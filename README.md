# Shelf Link – Manual QA Testing Portfolio

## Project Overview
Shelf Link is a smart electronic shelf labeling (ESL) platform designed for managing product information, categories, and pricing in retail environments.

This repository contains manual testing artifacts created to demonstrate QA skills and testing methodology.

---

## Scope of Testing
- Authentication (Login / Access control)
- Category management
- Product management
- Input validation
- Error handling
- ESL price update workflow (design-level)

---

## Testing Approach
- Requirement-based manual testing
- Test scenario and test case design
- Negative testing
- Bug reporting
- Blocked test documentation

---

## Tools Used
- Manual Testing
- GitHub (Documentation & version control)

---

## Limitations
- Login functionality was not working during execution
- Internal modules could not be accessed
- Test cases were designed based on requirements and expected workflows
- ESL hardware synchronization could not be tested

---

## Learning Outcomes
- Designed structured test scenarios and test cases
- Practiced professional handling of blocked test execution
- Created detailed bug reports
- Gained real-world QA documentation experience
