# Bug Report – Shelf Link

## Bug ID
SL-BUG-01

## Title
User unable to log in with valid credentials

## Environment
- Application: Shelf Link (Local)
- Browser: Google Chrome
- OS: Windows

## Severity
Critical

## Priority
High

## Steps to Reproduce
1. Open the Shelf Link application
2. Navigate to the login page
3. Enter valid username and password
4. Click Login

## Expected Result
User should be logged in and redirected to the dashboard

## Actual Result
Login is unsuccessful / application does not proceed

## Status
Open

## Notes
This issue blocks access to all internal modules such as Products and Categories.
